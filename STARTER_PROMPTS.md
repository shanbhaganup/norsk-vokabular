# Starter prompts

## Add a word

Add the Bokmål verb «forstå» using templates/02-verb.md. Check vocabulary/ for duplicates first, and check a reference snapshot if one is supplied. If promoting from a reference snapshot, do not count it as a new word. Verify applicable forms and write one natural Norwegian example with an English translation for every form. Update vocabulary/INDEX.md.

## Import a list

Compare the list in imports/ with the working vocabulary, and with a reference snapshot if one is supplied. Normalize inflected forms and ignore genuine duplicates. Add only new headword/type/sense entries with verified forms, bilingual examples and source notes. Keep uncertain translations in review/ and produce a merge report.

## Review an entry

Review vocabulary/verbs/skrive.md against its cited dictionary entry. Check every form and its example, including tense context, participle agreement and passive usage. Retain accepted alternatives and identify any uncertain points.

## Practise a topic

Use vocabulary/INDEX.md to find entries on the family topic. Give me five short translation exercises. Wait for my answers, then correct them and show the relevant forms. Keep the working vocabulary files unchanged during practice.
