## se på

**English:** to watch

**Topics:** entertainment

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Infinitiv | å se på | Vi kan komme til å se på filmen. | We may watch the movie. |
| Presens | ser på | Vi ser på filmen. | We watch the movie. |
| Preteritum | så på | I går så vi på filmen. | Yesterday, we watched the movie. |
| Perfektum partisipp | sett på | Vi har sett på filmen. | We have watched the movie. |
| Presens perfektum | har sett på | Vi har sett på filmen flere ganger. | We have watched the movie several times. |
| Preteritum perfektum | hadde sett på | Vi hadde sett på filmen før den tid. | We had watched the movie before then. |
| Futurum | skal se på | Vi skal se på filmen i morgen. | We will watch the movie tomorrow. |
| Futurum | vil se på | Vi vil se på filmen senere. | We will watch the movie later. |
| Futurum perfektum | skal ha sett på | Innen fredag skal vi ha sett på filmen. | By Friday, we will have watched the movie. |
| Futurum perfektum | vil ha sett på | Innen fredag vil vi ha sett på filmen. | By Friday, we will have watched the movie. |
| Kondisjonalis | ville se på | Vi ville se på filmen hvis det var mulig. | We would watch the movie if it were possible. |
| Kondisjonalis perfektum | ville ha sett på | Vi ville ha sett på filmen hvis det hadde vært mulig. | We would have watched the movie if it had been possible. |
| Framtid sett fra fortiden | skulle se på | Hun sa at vi skulle se på filmen dagen etter. | She said that we would watch the movie the following day. |
| Imperativ | se på | Se på filmen! | Watch the movie! |
| Presens partisipp | — | — | No independent adjectival present participle is used for this construction. |
| S-passiv, infinitiv | ses på | Filmen må ses på. | The movie must be watched. |
| S-passiv, infinitiv | sees på | Filmen må sees på. | The movie must be watched. |
| S-passiv, presens | ses på | Filmen ses på. | The movie is watched. |
| S-passiv, presens | sees på | Filmen sees på. | The movie is watched. |
| Bli-passiv, presens | blir sett på | Filmen blir sett på. | The movie is being watched. |
| Bli-passiv, preteritum | ble sett på | Filmen ble sett på. | The movie was watched. |
| Bli-passiv, perfektum | har blitt sett på | Filmen har blitt sett på. | The movie has been watched. |
| Partisipp som adjektiv, m./f. ubestemt | sett på | Vi snakket om en sett på film. | We talked about a watched movie. |
| Partisipp som adjektiv, intetkjønn | sett på | Vi snakket om et sett på program. | We talked about a watched program. |
| Partisipp som adjektiv, bestemt entall | sette på | Vi snakket om den sette på filmen. | We talked about the watched movie. |
| Partisipp som adjektiv, flertall | sette på | Vi snakket om to sette på filmer. | We talked about two watched movies. |
