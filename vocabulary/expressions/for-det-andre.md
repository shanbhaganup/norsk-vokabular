## for det andre

**English:** secondly, for another thing

**Topics:** communication

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Fast uttrykk | for det andre | For det andre trenger vi mer tid. | Secondly, we need more time. |
| Konstruksjon, rekkefølge | for det første … for det andre | For det første er det billig. For det andre er det enkelt. | First, it’s cheap. Second, it’s simple. |

**Form status:** Bokmålsordboka headword or constituent checked. Examples are original teaching sentences.

**Notes:** This fixed phrase introduces the second point in an argument or list.
