## så

**English:** so, therefore

**Topics:** communication

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Ordklasse | konjunksjon | Bussen var forsinket, så vi gikk hjem. | The bus was late, so we walked home. |
| Bøyning | ubøyelig | Vi var sultne, så vi lagde middag. | We were hungry, so we made dinner. |
| Konstruksjon, helsetninger | helsetning + så + helsetning | Det begynte å regne, så vi ble inne. | It started raining, so we stayed inside. |
