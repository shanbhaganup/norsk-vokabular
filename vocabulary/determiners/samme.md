## samme

**English:** the same

**Topics:** General / unassigned

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Type | demonstrativ | Vi valgte samme løsning. | We chose the same solution. |
| Hankjønn | samme | Vi tok samme buss hjem. | We took the same bus home. |
| Hunkjønn | samme | Vi fant fram den samme jakka som i går. | We got out the same jacket as yesterday. |
| Intetkjønn | samme | Vi bodde på samme hotell i fjor. | We stayed at the same hotel last year. |
| Flertall | samme | De stilte de samme spørsmålene i begge intervjuene. | They asked the same questions in both interviews. |
| Bruk uten substantiv | det samme | Jeg bestilte det samme som Eva. | I ordered the same thing as Eva. |

**Form status:** Spelling and usage checked in Bokmålsordboka. Examples are original teaching sentences.

**Notes:** Bokmålsordboka classifies samme as a demonstrative determiner. It has the same spelling across genders and numbers, and can stand without a following noun in det samme.
