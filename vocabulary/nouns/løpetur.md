## løpetur

**English:** a run, a running outing

**Topics:** sport

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | en | Vi tok en løpetur før frokost. | We went for a run before breakfast. |
| Entall ubestemt | løpetur | En kort løpetur hjelper meg å våkne. | A short run helps me wake up. |
| Entall bestemt | løpeturen | Løpeturen gikk langs fjorden. | The run followed the fjord. |
| Flertall ubestemt | løpeturer | Hun tar flere løpeturer i uka. | She goes on several runs a week. |
| Flertall bestemt | løpeturene | Løpeturene hennes varer omtrent en halvtime. | Her runs last about half an hour. |

**Form status:** Dictionary headword and gender checked. The reference snapshot supplies the cited inflection forms. Examples are original teaching sentences.

**Notes:** The source gloss ‘jogging’ is adjusted to ‘a run’ or ‘a running outing’. Bokmålsordboka defines *løpetur* as running a particular distance, especially as exercise. Its headword result confirms masculine gender; the cited reference article contains the full forms.
