## bruker

**English:** user

**Topics:** technology, services

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | en | En bruker kan endre innstillingene sine. | A user can change their settings. |
| Entall ubestemt | bruker | Hver bruker må opprette en konto. | Each user must create an account. |
| Entall bestemt | brukeren | Brukeren fikk en bekreftelse på e-post. | The user received a confirmation by email. |
| Flertall ubestemt | brukere | Mange brukere besøker nettsiden daglig. | Many users visit the website daily. |
| Flertall bestemt | brukerne | Brukerne kan sende inn spørsmål. | Users can submit questions. |

**Form status:** Bokmålsordboka forms checked. Examples are original teaching sentences.

**Notes:** A person who uses or owns/rents something.
