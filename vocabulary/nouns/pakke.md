## pakke

**English:** package

**Topics:** home

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | ei | Ei pakke lå ved døra. | A package was by the door. |
| Kjønn / artikkel | en | En pakke lå ved døra. | A package was by the door. |
| Entall ubestemt | pakke | Jeg fikk ei pakke i posten. | I received a package in the mail. |
| Entall bestemt | pakka | Pakka kom fram uten skade. | The package arrived without damage. |

**Form status:** Forms checked against Bokmålsordboka. Original teaching examples and translations.

**Notes:** Both feminine and masculine gender are accepted. The examples use the concrete parcel sense. The dictionary also has a coordinated package or set of measures sense.
