## hacking

**English:** hacking (unauthorized access to computer systems; also security testing and exploratory IT work)

**Topics:** technology

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | ei / en | Ei hacking av kontoen ble oppdaget raskt. / En hacking av kontoen ble oppdaget raskt. | A hack of the account was detected quickly. / A hack of the account was detected quickly. |
| Entall ubestemt | hacking | Etisk hacking kan avdekke sikkerhetshull. | Ethical hacking can uncover security vulnerabilities. |
| Entall bestemt | hackinga / hackingen | Hackinga av serveren ble undersøkt. / Hackingen av serveren ble undersøkt. | The hacking of the server was investigated. / The hacking of the server was investigated. |
| Flertall ubestemt | hackinger | Selskapet registrerte flere hackinger av systemet i fjor. | The company recorded several hacking incidents involving the system last year. |
| Flertall bestemt | hackingene | Hackingene ble meldt til sikkerhetsavdelingen. | The hacking incidents were reported to the security department. |

**Form status:** Dictionary entry gives masculine or feminine gender and lists these forms; source forms retained.

**Notes:** The dictionary covers both unauthorized access and testing or finding new IT solutions. The plural is unusual for the activity as a mass noun, but can count separate incidents; the examples use it in that countable sense. Masculine and feminine article and definite-singular alternatives are both shown.
