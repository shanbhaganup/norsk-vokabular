## kode

**English:** code; passcode; set of rules or symbols

**Topics:** technology, communication

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | en | En kode beskytter tilgangen til kontoen. | A code protects access to the account. |
| Entall ubestemt | kode | Skriv inn en kode for å åpne døra. | Enter a code to open the door. |
| Entall bestemt | koden | Koden til nettverket står på ruteren. | The network code is printed on the router. |
| Flertall ubestemt | koder | Programmerere skriver koder som styrer appen. | Programmers write code that controls the app. |
| Flertall bestemt | kodene | Kodene må lagres på en sikker måte. | The codes must be stored securely. |
