## anmodning

**English:** request (often formal)

**Topics:** communication

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | ei | Ei skriftlig anmodning kom fra styret. | A written request came from the board. |
| Kjønn / artikkel | en | Hun sendte en anmodning om mer tid. | She sent a request for more time. |
| Entall ubestemt | anmodning | På anmodning fra skolen ble møtet flyttet. | At the school’s request, the meeting was moved. |
| Entall bestemt | anmodninga | Anmodninga ble avslått samme dag. | The request was rejected that same day. |
| Entall bestemt | anmodningen | Sekretæren la anmodningen fram for styret. | The secretary presented the request to the board. |
| Flertall ubestemt | anmodninger | Kontoret mottok flere anmodninger om innsyn. | The office received several requests for access to records. |
| Flertall bestemt | anmodningene | Anmodningene ble behandlet i den rekkefølgen de kom inn. | The requests were handled in the order they came in. |

**Form status:** Verified against Bokmålsordboka. Original teaching examples and translations.

**Notes:** Both genders are accepted in Bokmål. The word is common in formal or administrative language.
