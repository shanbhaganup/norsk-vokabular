## beskrivelse

**English:** description

**Topics:** communication

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | en | Hun ga en nøyaktig beskrivelse av stedet. | She gave an accurate description of the place. |
| Entall ubestemt | beskrivelse | Rapporten inneholder en beskrivelse av arbeidet. | The report contains a description of the work. |
| Entall bestemt | beskrivelsen | Beskrivelsen passet til huset vi så. | The description matched the house we saw. |
| Flertall ubestemt | beskrivelser | Boka inneholder flere beskrivelser av byen. | The book contains several descriptions of the city. |
| Flertall bestemt | beskrivelsene | Vi sammenlignet beskrivelsene fra de to vitnene. | We compared the two witnesses’ descriptions. |

**Form status:** Bokmålsordboka forms checked. Examples are original teaching sentences.

**Notes:** A description gives details about someone or something.
