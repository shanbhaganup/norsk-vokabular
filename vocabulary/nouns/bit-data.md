## bit

**English:** bit (unit of digital information)

**Topics:** technology

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | en | En bit lagrer verdien null eller én. | A bit stores the value zero or one. |
| Entall ubestemt | bit | En bit kan lagre enten null eller én. | This bit is set to one. |
| Entall bestemt | biten | Biten representerer én binær verdi. | The bit represents one binary value. |
| Flertall ubestemt | bit | Filen inneholder åtte bit. | The file contains eight bits. |
| Flertall ubestemt | biter | Filen inneholder åtte biter. | The file contains eight bits. |
| Flertall bestemt | bitene | Bitene overføres til serveren. | The bits are transferred to the server. |
