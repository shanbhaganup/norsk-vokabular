## imøtekommende

**English:** approachable

**Topics:** behavior

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Positiv hankjønn | imøtekommende | Vi snakket om en imøtekommende leder. | We talked about an approachable manager. |
| Positiv hunkjønn | imøtekommende | Vi snakket om ei imøtekommende jente. | We talked about an approachable girl. |
| Positiv intetkjønn | imøtekommende | Vi snakket om et imøtekommende personale. | We talked about an approachable staff. |
| Positiv flertall | imøtekommende | Vi snakket om to imøtekommende ledere. | We talked about two approachable managers. |
| Positiv bestemt entall | imøtekommende | Vi snakket om den imøtekommende lederen. | We talked about the approachable manager. |
| Komparativ | mer imøtekommende | Denne lederen er mer imøtekommende enn den andre. | This manager is more approachable than the other one. |
| Superlativ ubestemt | mest imøtekommende | Av de to er denne lederen mest imøtekommende. | Of the two, this manager is the most approachable. |
| Superlativ bestemt | mest imøtekommende | Vi snakket om den mest imøtekommende lederen. | We talked about the most approachable manager. |

**Form status:** Dictionary spelling and agreement checked.

**Notes:** Comparison with mer and mest is a productive construction. NoW source form: “imøtekommende”. The bilingual examples are original teaching sentences.
