**Form status:** Bokmålsordboka verifies both invariable spellings, lignende and liknende. Synthetic comparison is not listed.

**Notes:** Bokmålsordboka accepts the spelling variant liknende as well as lignende. The source record uses lignende. More similarity is usually expressed with mer lik, where lik is a separate adjective, so it is not included as an inflection of lignende.
