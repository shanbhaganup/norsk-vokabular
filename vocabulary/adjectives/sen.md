## sen

**English:** late; slow; occurring later

**Topics:** time, describing

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Positiv hankjønn | sen / sein | Bussen var sen på grunn av trafikken. / Bussen var sein på grunn av trafikken. | The bus was late because of the traffic. / The bus was late because of the traffic. |
| Positiv hunkjønn | sen / sein | Ferga var sen i kveld. / Ferga var sein i kveld. | The ferry was late this evening. / The ferry was late this evening. |
| Positiv intetkjønn | sent / seint | Toget kom sent fram. / Toget kom seint fram. | The train arrived late. / The train arrived late. |
| Positiv flertall | sene / seine | De sene avlingene ble høstet i oktober. / De seine avlingene ble høstet i oktober. | The late crops were harvested in October. / The late crops were harvested in October. |
| Positiv bestemt entall | sene / seine | Den sene avgangen ble innstilt. / Den seine avgangen ble innstilt. | The late departure was cancelled. / The late departure was cancelled. |
| Komparativ | senere / seinere | Den senere avgangen passer bedre. / Den seinere avgangen passer bedre. | The later departure works better. / The later departure works better. |
| Superlativ ubestemt | senest / seinest | Av alle kom den siste pakken senest. / Av alle kom den siste pakken seinest. | Of them all, the last package arrived latest. / Of them all, the last package arrived latest. |
| Superlativ bestemt | seneste / seineste | Dette er den seneste utgaven. / Dette er den seineste utgaven. | This is the latest edition. / This is the latest edition. |

**Form status:** Dictionary forms and comparison checked; original teaching examples.

**Notes:** The source record “sein” is merged here because it is an accepted variant in the canonical sen entry.

**Notes:** Bokmålsordboka accepts both sen and sein inflection series; the reference lists only sen forms, so the accepted sein alternatives have been added and exemplified. The adjective includes slow, late, and later-in-time senses; the adverbial uses of sent/seint and senere/seinere are not treated as adjective forms here.
