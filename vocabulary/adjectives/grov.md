## grov

**English:** coarse; rough; crude; serious

**Topics:** describing

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Positiv hankjønn | grov | Han brukte en grov pensel. | He used a coarse brush. |
| Positiv hunkjønn | grov | Hun siktet med ei grov sil. | She sifted with a coarse sieve. |
| Positiv intetkjønn | grovt | De kjøpte et grovt brød. | They bought a coarse-grained loaf. |
| Positiv flertall | grove | Vi trenger grove sandpapirark. | We need coarse sheets of sandpaper. |
| Positiv bestemt entall | grove | Den grove sanden ble liggende igjen. | The coarse sand was left behind. |
| Komparativ | grovere | Denne sanden er grovere enn den andre. | This sand is coarser than the other. |
| Superlativ ubestemt | grovest | Start med det groveste papiret. | Start with the coarsest paper. |
| Superlativ ubestemt | grøvst | Start med det grøvste papiret. | Start with the coarsest paper. |
| Superlativ bestemt | groveste | Dette er den groveste sanden i prøven. | This is the coarsest sand in the sample. |
| Superlativ bestemt | grøvste | Dette er den grøvste sanden i prøven. | This is the coarsest sand in the sample. |

**Form status:** Verified; both dictionary-listed superlative variants are illustrated.

**Notes:** The dictionary lists grovest / grøvst and groveste / grøvste. Both alternatives are accepted and illustrated. Grov has several senses; these examples use the coarse-grained sense.
