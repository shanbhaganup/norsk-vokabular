## anerkjent

**English:** well-regarded

**Topics:** work

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Positiv hankjønn | anerkjent | Vi snakket om en anerkjent forsker. | We talked about a well-regarded researcher. |
| Positiv hunkjønn | anerkjent | Vi snakket om ei anerkjent gruppe. | We talked about a well-regarded group. |
| Positiv intetkjønn | anerkjent | Vi snakket om et anerkjent tidsskrift. | We talked about a well-regarded journal. |
| Positiv flertall | anerkjente | Vi snakket om to anerkjente forskere. | We talked about two well-regarded researchers. |
| Positiv bestemt entall | anerkjente | Vi snakket om den anerkjente forskeren. | We talked about the well-regarded researcher. |
| Komparativ | mer anerkjent | Denne forskeren er mer anerkjent enn den andre. | This researcher is more well-regarded than the other one. |
| Superlativ ubestemt | mest anerkjent | Av de to er denne forskeren mest anerkjent. | Of the two, this researcher is the most well-regarded. |
| Superlativ bestemt | mest anerkjente | Vi snakket om den mest anerkjente forskeren. | We talked about the most well-regarded researcher. |
