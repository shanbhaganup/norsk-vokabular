## ulik

**English:** different

**Topics:** describing

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Positiv hankjønn | ulik | Vi snakket om en ulik modell. | We talked about a different model. |
| Positiv hunkjønn | ulik | Vi snakket om ei ulik løsning. | We talked about a different solution. |
| Positiv intetkjønn | ulikt | Vi snakket om et ulikt resultat. | We talked about a different result. |
| Positiv flertall | ulike | Vi snakket om to ulike løsninger. | We talked about two different solutions. |
| Positiv bestemt entall | ulike | Vi snakket om den ulike modellen. | We talked about the different model. |
| Komparativ | mer ulik | Denne modellen er mer ulik enn den andre. | This model is more different than the other one. |
| Superlativ ubestemt | mest ulik | Av de to er denne modellen mest ulik. | Of the two, this model is the most different. |
| Superlativ bestemt | mest ulike | Vi snakket om den mest ulike modellen. | We talked about the most different model. |

**Notes:** Comparison with mer and mest is a productive construction. NoW source form: “ulik”. The bilingual examples are original teaching sentences.
