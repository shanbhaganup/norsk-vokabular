## avhengig

**English:** dependent

**Topics:** describing

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Positiv hankjønn | avhengig | Vi snakket om en avhengig bruker. | We talked about a dependent user. |
| Positiv hunkjønn | avhengig | Vi snakket om ei avhengig gruppe. | We talked about a dependent group. |
| Positiv intetkjønn | avhengig | Vi snakket om et avhengig land. | We talked about a dependent country. |
| Positiv flertall | avhengige | Vi snakket om to avhengige brukere. | We talked about two dependent users. |
| Positiv bestemt entall | avhengige | Vi snakket om den avhengige brukeren. | We talked about the dependent user. |
| Komparativ | mer avhengig | Denne brukeren er mer avhengig enn den andre. | This user is more dependent than the other one. |
| Superlativ ubestemt | mest avhengig | Av de to er denne brukeren mest avhengig. | Of the two, this user is the most dependent. |
| Superlativ bestemt | mest avhengige | Vi snakket om den mest avhengige brukeren. | We talked about the most dependent user. |
