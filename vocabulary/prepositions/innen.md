## innen

**English:** by; within

**Topics:** time

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Bøyning | ubøyelig | Send søknaden innen fredag. | Send the application by Friday. |
| Tidsfrist | innen | Send søknaden innen fredag. | Send the application by Friday. |
| Tidsrom | innen | Du får svar innen to uker. | You’ll get a reply within two weeks. |

**Form status:** Dictionary spelling and usage checked.

**Notes:** With a date, innen sets the latest time. With a duration, it sets a time window. NoW source form: “innen”. The bilingual examples are original teaching sentences.
