## om

**English:** whether, if

**Topics:** General / unassigned

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Ordklasse | subjunksjon | Jeg vet ikke om hun kommer. | I don’t know whether she’s coming. |
| Bøyning | ubøyelig | Han spurte om vi hadde tid. | He asked if we had time. |
| Konstruksjon | om + leddsetning | Sjekk om døra er låst. | Check whether the door is locked. |

**Form status:** Bokmålsordboka headword or constituent checked. Examples are original teaching sentences.

**Notes:** Om introduces an indirect yes–no question.
