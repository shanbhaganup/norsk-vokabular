## så

**English:** so that

**Topics:** communication

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Ordklasse | subjunksjon | Snakk høyere så alle hører deg. | Speak louder so that everyone can hear you. |
| Bøyning | ubøyelig | Lukk døra så hunden ikke løper ut. | Close the door so the dog doesn’t run out. |
| Konstruksjon, formål | så + subjekt + verbal | Skriv datoen øverst så vi finner den med en gang. | Write the date at the top so that we can find it right away. |

**Form status:** Bokmålsordboka headword or usage checked. Examples are original teaching sentences.

**Notes:** This use introduces a subordinate clause that expresses purpose or intended result.
