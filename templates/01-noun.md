## Copyable structure

Copy the structure below into a vocabulary file, replace every placeholder, and add the metadata described in the project guide. Each applicable form needs its own example and English translation. For a form that does not apply, write — and explain the reason; do not invent a sentence for it.

```markdown
## [Word]

**English:** [Meaning]

**Topics:** [Topic(s)]

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | [Form or feature] | [One sentence using this form] | [English translation] |
| Entall ubestemt | [Form or feature] | [One sentence using this form] | [English translation] |
| Entall bestemt | [Form or feature] | [One sentence using this form] | [English translation] |
| Flertall ubestemt | [Form or feature] | [One sentence using this form] | [English translation] |
| Flertall bestemt | [Form or feature] | [One sentence using this form] | [English translation] |

**Form status:** [Verified / derived / unverified / inapplicable]

**Notes:** [Alternatives, restrictions, grammar and source uncertainty]

**Sources:**

- [Source title](https://example.org)
```

## Worked example

## jente

**English:** girl

**Topics:** family

| Form / feature | Value | Norwegian example | English translation |
| --- | --- | --- | --- |
| Kjønn / artikkel | ei / en | Ei jente står her. / En jente står her. | A girl is standing here. / A girl is standing here. |
| Entall ubestemt | jente | Jeg ser ei jente. | I see a girl. |
| Entall bestemt | jenta / jenten | Jenta leser. / Jenten leser. | The girl is reading. / The girl is reading. |
| Flertall ubestemt | jenter | Tre jenter spiller fotball. | Three girls are playing football. |
| Flertall bestemt | jentene | Jentene venter på bussen. | The girls are waiting for the bus. |

**Form status:** Dictionary headword/forms checked; compound constructions and original example sentences supplied for teaching.

**Notes:** Both feminine and masculine inflection are accepted in Bokmål. Choose a consistent pattern within a sentence. The alternatives below each have an example.
